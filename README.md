# AIGC Video Studio

面向生产环境的多模态营销视频生成平台。系统接收商品素材和营销需求，依次完成
分镜审核、视频片段生成、配音、字幕、成片合成和质量报告生成。

仓库目前处于基础建设阶段，后续将按照里程碑逐步加入运行依赖和业务功能。

## 架构方向

后端初期采用模块化单体架构，并将后台任务进程作为可独立部署单元。这既能保持
清晰的业务边界，也能避免过早引入不必要的分布式网络边界。

```text
前端 -> API -> 应用服务 -> 领域层
              |              |
              |              +-> 工作流 -> 模型供应商
              +-> 数据库 / 队列 / 对象存储
                                  |
                                  +-> 后台任务进程
```

## 仓库结构

```text
.
|-- frontend/                 # React/TypeScript 前端，后续阶段引入
|-- src/aigc_video_studio/
|   |-- api/                  # HTTP 传输层与 API 版本管理
|   |-- application/          # 用例、命令、查询与流程协调
|   |-- domain/               # 业务模型、业务规则与领域服务
|   |-- infrastructure/       # 数据库、队列与存储的具体实现
|   |-- integrations/         # LLM、VLM、视频和 TTS 供应商适配器
|   |-- workflows/            # 可持久化的 LangGraph 工作流
|   |-- workers/              # 长时间运行的异步任务入口
|   |-- observability/        # 日志、链路追踪、指标与成本监控
|   `-- shared/               # 仅存放少量跨模块基础组件
|-- tests/
|   |-- unit/                 # 隔离且结果确定的单元测试
|   |-- integration/          # 数据库、队列、存储和供应商集成测试
|   |-- contract/             # API 与外部供应商契约测试
|   `-- e2e/                  # 完整用户流程端到端测试
|-- evals/                    # 固定数据集与模型质量评测
|-- docs/
|   |-- architecture/         # 架构文档
|   |-- adr/                  # 架构决策记录
|   `-- runbooks/             # 运维与故障处理手册
|-- deployments/              # Docker 与环境部署资源
`-- scripts/                  # 可重复执行的开发和运维脚本
```

## 开发状态

仓库基础结构已经就绪。下一个里程碑将固定 Python 运行时版本，并加入 API、配置、
数据持久化、数据库迁移、测试、代码检查和类型检查工具链。

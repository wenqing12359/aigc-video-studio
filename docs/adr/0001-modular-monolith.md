# ADR 0001：采用模块化单体和独立后台任务进程

- 状态：已接受
- 日期：2026-11-05

## 背景

产品包含紧密关联的项目、商品、分镜、生成、审核和评测工作流。视频生成和合成属于
长时间运行的任务，但初期团队规模和业务流量不足以支撑为每个领域分别建设网络服务
所带来的运维成本。

## 决策

建设一个带版本的 API 应用，并明确划分领域层、应用层和基础设施层。长时间运行的
任务通过持久化队列交给可独立部署的后台任务进程执行。所有外部模型供应商都封装在
适配器之后。

## 影响

- 本地开发和事务性修改保持简单直接。
- 重型任务可以独立于 HTTP 请求处理进行扩缩容，并隔离运行失败。
- 必须通过代码评审和测试维护模块边界。
- 只有经过实际测量，确认扩缩容、团队归属或可靠性要求足以抵消额外运维成本时，
  才将相应模块拆分为独立服务。
